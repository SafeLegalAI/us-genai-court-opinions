Your job: find the **same document on the issuing court's own website or an official/primary repository**, confirm it is the same document, and record it. Nothing else changes.

## Where to look (official/primary only)
State appellate and supreme courts publish opinions on their own sites: e.g. NY — nycourts.gov/reporter (Official Reports: `nycourts.gov/reporter/3dseries/...`) and the Appellate Division decision pages; TX — search.txcourts.gov (Case search → Documents); FL — supremecourt.flcourts.gov / each DCA's opinion archive (`flcourts-media.flcourts.gov`); GA — gaappeals.gov / gasupreme.us (efast.gaappeals.gov PDFs); CA — courts.ca.gov/opinions (published) and appellate case information for unpublished; AZ — azcourts.gov opinions; IL — ilcourts.gov (Rule 23 orders under "Rule 23 Orders", opinions under "Supreme/Appellate Court Opinions"; PDFs at `ilcourtsaudio.blob.core.windows.net` are official); OH — supremecourt.ohio.gov/rod (Reporter of Decisions, also carries appellate districts); IA — iowacourts.gov; IN — public.courts.in.gov/decisions; PA — pacourts.us opinions; MD — mdcourts.gov/appellate/opinions (and unreported); WA — courts.wa.gov/opinions; OR — cdm17027.contentdm.oclc.org / courts.oregon.gov; MN — mncourts.gov/archive; DE — courts.delaware.gov/opinions; DC — dccourts.gov. Trial-court orders: the county/court's own site or its case-search system if public without login. If a state uses a public case-information system that serves PDFs without login, that counts. **CourtListener**: allowed only via the anonymous search API within Free Law Project's published limits (≤5 requests/min, ≤50/hour, ≤125/day *shared across all agents* — so use it sparingly: at most 20 requests per agent, for discovery only); never crawl courtlistener.com HTML; `storage.courtlistener.com` PDFs (the public RECAP archive) are an acceptable primary copy when the court site has none.

## Never
Never use Westlaw, Lexis, Justia, Casetext, Google Scholar, Leagle, FindLaw, CaseMine, vLex, Law360 or any aggregator as `source_url`, and do not fetch them programmatically. Never fetch CanLII/AustLII/BAILII (not relevant here anyway). Identify yourself (`User-Agent: SafeLegalAI-Bot/1.0 (+https://safelegalai.com/datasets; hello@safelegalai.com)`), ≤1 request/second per host, obey robots.txt. Do not guess a URL and mark it found — **a row is resolved only when you fetched the document and located the quoted passage in it.**

## How to confirm
Download the candidate PDF/HTML; extract text (`pdftotext -layout`); confirm the row's `ai_passage` (first 160 chars are in the queue as `passage_head`; the full passage is in the row) appears, allowing for footnote numbers, page headers and hyphenation. Compute `sha256` of the fetched bytes.

## How to record
Edit the row in place in the `work/agents/decisions-*.jsonl` file that holds it (find by `decision_id`): set `source_url` to the official URL, add `mirror_url` = the old `source_url`, set `verification` = `fetched-and-read`, `fetched_at` = today (ISO), `text_sha256` = the new hash, and append to `notes`: `"Official copy located <date> at <host>; quoted passage confirmed."` (remove "official copy pending" if present). If the court publishes the document only behind a login/paywall or does not publish it (common for trial-court orders), leave the row unchanged and append to `notes`: `"Official copy not published online as of <date> (checked <where>)."` — that is a valid, useful finding. Write a one-line result per row to `work/resolve/results-<LETTER>.jsonl`: `{"decision_id","status":"resolved|not-published|not-found","official_url","checked":[hosts],"note"}`.

Do not touch `data/` (the release is rebuilt afterwards). Do not change any other field. Finish with a 5-line summary: resolved / not-published / not-found counts and anything odd (e.g. the mirror PDF differs materially from the official one — flag that loudly with both URLs).
